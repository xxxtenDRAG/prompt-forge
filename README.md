# Game Prompt Forge 🎮🔨

> 单机游戏创意孵化与提示词锻造 Skill —— 一句话想法，一轮对齐，一个完整游戏。

## 解决什么问题

你只有一个念头："我想做个消消乐单机游戏。"

其他一概没有想法：没有题材、没有关卡设计、没有数值、没有界面构思。

正常情况下 AI 会连环追问、反复返工，来回对齐十几轮才能开工——每一轮都在烧积分。

这个 skill 把整个流程压缩成：

```
一句话想法
   │
   ▼
一次批量确认（4 个问题，可全部用默认值）
   │
   ▼
AI 内部九视角推演（玩法 / 关卡 / 数值 / UX / 视听 / 留存 / 技术 / 可访问性 / QA）
   │
   ▼
《游戏设计蓝图》 + 可直接执行的开发提示词
   │
   ▼
一轮开发交付完整游戏（含教学、反馈、存档、验收自检）
```

**核心思路：用一次性的内部多视角推演代替多轮外部对齐。** AI 扮演九个专家把方案一次想透，替你拍板所有细节（并列出"已自动补全的决策"供你事后一键修改），最后锻造出一份零决策、纯实现的开发提示词——开发 AI 拿到后不需要再做任何方案决策，积分都花在写代码上。

## 一次运行产出三件套

1. **《游戏设计蓝图》** — 面向人看的完整方案
2. **开发提示词** — 面向 AI 执行的压缩指令
3. **完整可玩的游戏** — 通过 9 项验收清单自检的成品

## 目录结构

```
game-prompt-forge/
├── SKILL.md                              # Skill 主文件（工作流与触发规则）
└── references/
    ├── game-design-lenses.md             # 九专家视角推演清单 + QA 验收清单
    ├── gdd-template.md                   # 设计蓝图模板
    ├── dev-prompt-template.md            # 开发提示词锻造模板与压缩规则
    └── genre-playbooks.md                # 8 种常见玩法速查（消消乐/贪吃蛇/跑酷/塔防...）
```

## 使用方法

### WorkBuddy 用户

1. 把 `game-prompt-forge/` 文件夹复制到 `~/.workbuddy/skills/`（用户级，全项目可用）或项目的 `.workbuddy/skills/` 目录。
2. 对 AI 说："帮我做个消消乐单机游戏"——skill 会自动触发。

### 任何 AI 助手用户

即使不用 WorkBuddy，这套文件本身也可以手动使用：

1. 把 `references/` 下四个文件连同你的想法一起发给任意 AI；
2. 让它按 `SKILL.md` 的 Phase 1–4 走完，产出蓝图和开发提示词；
3. 把开发提示词原样发给开发用的 AI，拿到完整游戏。

## 设计原则

- **默认值优先**：全程只问一次问题，且附带默认值，回一句"都用默认"即可开工。
- **单机约束**：零后端、零账号、离线可玩，默认单文件 HTML 双击即玩。
- **拍板透明**：AI 替你做的所有决策集中列出，随时改、快速重跑。
- **验收兜底**：9 项 QA 清单逐项自检，浏览器实际运行无报错才算交付。
