# Prompt Forge 🔨

> 通用创意孵化与提示词锻造 Skill —— 一句话想法，一轮对齐，一个完整成品。

## 解决什么问题

你只有一个念头："我想做个消消乐""帮我弄个个人网站""写份行业分析报告""做个文件改名工具"。

其他一概没有想法：没有结构、没有细节、没有参数、没有审美倾向。

正常情况下 AI 会连环追问、反复返工，来回对齐十几轮才能开工——每一轮都在烧积分。

这个 skill 把整个流程压缩成：

```
一句话想法
   │
   ▼
任务类型识别（游戏 / 网站 / 工具 / 文档 / 数据分析 / 其他）
   │
   ▼
一次批量确认（≤4 个问题，可全部用默认值）
   │
   ▼
AI 内部多视角推演（目标 / 受众 / 架构 / 打磨 / 风险 / 容错 / QA + 领域专属视角）
   │
   ▼
《方案蓝图》 + 可直接执行的提示词
   │
   ▼
一轮执行交付完整成品（逐项验收自检）
```

**核心思路：用一次性的内部多视角推演代替多轮外部对齐。** AI 扮演一组专家把方案一次想透，替你拍板所有细节（并列出"已自动补全的决策"供你事后一键修改），最后锻造出一份零决策、纯实现的执行提示词——执行 AI 拿到后不需要再做任何方案决策，积分都花在干活上。

## 一次运行产出三件套

1. **《方案蓝图》** — 面向人看的完整方案
2. **执行提示词** — 面向 AI 执行的压缩指令
3. **完整成品** — 通过验收清单自检的交付物

## 目录结构

```
prompt-forge/
├── SKILL.md                          # Skill 主文件（工作流与触发规则）
└── references/
    ├── universal-lenses.md           # 通用七视角推演清单 + QA 验收框架
    ├── blueprint-template.md         # 方案蓝图模板
    ├── dev-prompt-template.md        # 执行提示词锻造模板与压缩规则
    ├── playbook-game.md              # 游戏 Playbook：九视角深化清单
    ├── playbook-genres.md            # 游戏 Playbook：8 种常见玩法速查
    ├── playbook-web.md               # 网站/应用速查基线
    ├── playbook-tool.md              # 小工具/脚本速查基线
    ├── playbook-doc.md               # 文档/报告速查基线
    └── playbook-data.md              # 数据分析速查基线
```

## 覆盖的任务类型

| 类型 | 例子 | 推演基线 |
|------|------|----------|
| 游戏 | "做个消消乐单机游戏" | 九视角深化 + 玩法速查 |
| 网站/应用 | "帮我弄个作品集网站" | 信息架构 + 视觉体验基线 |
| 小工具 | "写个批量改名脚本" | 输入输出 + 健壮性基线 |
| 文档/报告 | "写份竞品分析报告" | 结构主线 + 内容质量基线 |
| 数据分析 | "分析下这份数据" | 问题定义 + 口径验证基线 |
| 其他 | 任何一句话想法 | 通用七视角从零推演 |

## 使用方法

### WorkBuddy 用户

1. 把 `prompt-forge/` 文件夹复制到 `~/.workbuddy/skills/`（用户级，全项目可用）或项目的 `.workbuddy/skills/` 目录。
2. 对 AI 说："帮我做个消消乐" / "帮我弄个网站"——skill 会自动触发。

### 任何 AI 助手用户

即使不用 WorkBuddy，这套文件本身也可以手动使用：

1. 把 `references/` 下所需文件连同你的想法一起发给任意 AI；
2. 让它按 `SKILL.md` 的 Phase 1–4 走完，产出蓝图和执行提示词；
3. 把执行提示词原样发给干活的 AI，拿到完整成品。

## 设计原则

- **默认值优先**：全程只问一次问题，且附带默认值，回一句"都用默认"即可开工。
- **拍板透明**：AI 替你做的所有决策集中列出，随时改、快速重跑。
- **提示词零决策**：锻造出的执行提示词消除一切方案空白，AI 只做实现。
- **验收兜底**：通用底线项 + 领域专属项双重清单逐项自检，实际运行验证过才算交付。
