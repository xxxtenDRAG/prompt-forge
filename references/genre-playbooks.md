# 常见单机玩法速查（Genre Playbooks）

用户输入命中以下玩法时，直接以对应条目为推演基线，在其基础上做题材化与数值细化，不要从零发明规则。未命中的玩法按九视角从零推演。

---

## 消消乐（三消 Match-3）

- **核心循环**：交换相邻元素 → 三连及以上消除 → 上方下落补位 → 可能触发连锁。
- **判定要点**：仅横竖算连，斜向不算；交换后无消除则回弹；棋盘必须保底存在可行步，否则自动洗牌。
- **深度机制基线**：连锁 Combo 倍率、四连/五连生成特殊元素（行清/炸弹）、步数或时间双模式。
- **常见坑**：死局检测缺失、消除判定在补位动画期间重复触发。

## 贪吃蛇

- **核心循环**：方向控制移动 → 吃食物变长 → 撞墙/撞自己结束。
- **判定要点**：转向输入缓存队列（防止一帧内两次转向导致自撞）；速度渐进提升。
- **深度机制基线**：加速食物、穿墙道具、障碍关卡模式。
- **常见坑**：输入丢失导致"按了没反应"、无暂停。

## 跑酷（Endless Runner）

- **核心循环**：自动前进 → 跳/滑躲避 → 距离即分数 → 撞障碍结束。
- **判定要点**：跳跃可变高度（按住跳更高）、碰撞盒比视觉小 20%（宽容手感）。
- **深度机制基线**：速度爬坡、金币与道具（护盾/磁铁）、随机路段拼接。
- **常见坑**：不可反应的速度突增、碰撞判定过严。

## 塔防

- **核心循环**：放置炮塔 → 敌人沿路径进攻 → 击杀得金币 → 买/升级炮塔。
- **判定要点**：塔的射程/攻速/伤害三轴差异化；敌人波次表固定出怪顺序（保底可通关）。
- **深度机制基线**：塔升级三级、敌人类型（快/坦/群体）、关卡多路径。
- **常见坑**：经济不平衡导致中期必败、塔之间无克制关系。

## 俄罗斯方块

- **核心循环**：下落块 → 旋转/平移 → 满行消除 → 堆顶结束。
- **判定要点**：软降/硬降、旋转踢墙（SRS 简化版）、显示下一块。
- **深度机制基线**：消行数对应分数倍率、等级提速表、连消奖励。
- **常见坑**：旋转穿墙、锁定后仍可移动导致抖动。

## 2048

- **核心循环**：方向滑动 → 全盘合并同数 → 随机生成新块 → 无法移动结束。
- **判定要点**：一次滑动可多次合并但每块每回合只合并一次；新块 90% 出 2、10% 出 4。
- **深度机制基线**：分数、最高块记录、撤销一步。
- **常见坑**：合并顺序错误（应从移动方向最远端开始）、死局判定遗漏单格可动。

## 弹幕射击（Space Shooter / 打飞机）

- **核心循环**：移动躲避 → 射击 → 击落敌机得分 → 被击中结束。
- **判定要点**：玩家碰撞盒极小（核心判定）、敌人波次化、弹幕有规律可读。
- **深度机制基线**：武器升级、护盾/生命、Boss 战。
- **常见坑**：敌弹速度过快不可躲、难度无爬坡。

## 点击放置（Idle / Clicker）

- **核心循环**：点击产出资源 → 购买升级提效率 → 挂机累积 → 解锁层级。
- **判定要点**：产出公式指数化但回本时间递增；离线收益按时间结算（单机用时间戳计算）。
- **深度机制基线**：转生/重置加成、成就、自动购买解锁。
- **常见坑**：数值爆炸溢出、早期无反馈导致无聊。

## 使用规则

1. 命中条目后，先抄基线规则进蓝图第 2 节，再做三件事：题材化包装、按用户亮点定制机制、给出本作数值表。
2. 条目中的"常见坑"必须写入蓝图技术要点，开发提示词里要求针对性规避。
3. 组合玩法（如"消消乐+塔防"）以主玩法为基线，副玩法作为变化机制写入第 3 节。
