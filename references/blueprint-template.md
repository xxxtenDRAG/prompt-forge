# 方案蓝图模板（Blueprint）

Phase 3 按本模板输出《方案蓝图》，适用于任何任务类型。目标是"人能看懂、AI 能照做"：每个条目必须写结论，不允许出现"待定""视情况而定"。篇幅按任务规模控制在 600–2000 字。

---

## 写作规则

1. 蓝图开头必须先放"已自动补全的决策"清单——这是用户唯一需要回看并可能修改的部分。
2. 规则与结构描述写到"一个新人照做不会有第二种理解"的精度。
3. 参数给出具体数字，不给模糊词。
4. 若任务命中 playbook，第 2、3 节以速查条目为基线扩展，不要推翻重写。
5. 蓝图是中间产物：展示后直接进入 Phase 4，不等用户逐条确认。
