# 网站 Playbook — 网站与应用速查基线

网站/应用类任务在通用七视角基础上叠加本基线。默认约束：静态或轻后端、响应式、移动端可用、现代浏览器兼容、首屏 2 秒内可交互。

---

## 信息架构

- 页面清单定死：首页 + 3–6 个内容页/功能区，每个页面一句话职责（超出即砍）。
- 导航不超过 7 项；任何页面 3 次点击内到达核心内容。
- 定义每个页面的"唯一关键动作"（注册、联系、阅读完、下单），全页围绕它排布。

## 视觉与体验

- 三色体系：主色（品牌）、强调色（按钮/高亮）、中性色（背景/文字），对比度 ≥ WCAG AA。
- 首屏必须有：一句价值主张 + 关键动作入口 + 一张视觉主元素。
- 反馈：按钮悬停/点击态、表单校验提示、加载占位、空状态文案齐备。
- 动效克制：过渡 150–300ms，只用于引导注意，不做纯装饰。

## 内容与文案

- 每页标题信息优先，正文段落在移动端 4–6 行内。
- CTA 文案写动作与收益（"免费生成报告"优于"提交"）。
- 页脚与版权、联系入口齐全。

## 技术基线

- 默认零依赖单文件或单目录静态站；需要后端/账号/存库时先确认必要性再选托管方案。
- 图片优先 SVG/CSS 绘制，避免外部图库依赖；必须用图时准备无图降级。
- localStorage 保存用户偏好；表单本地校验 + 提交反馈。

## 专属验收项（叠加进验收清单）

- [ ] 所有页面/路由可达，无死链、无 404。
- [ ] 移动端 375px 宽度下布局不破、文字不溢出。
- [ ] 每页关键动作明确且可完成（点得动、交得上去、看得到反馈）。
- [ ] 浏览器控制台无报错；首次打开无横向滚动条。
- [ ] 视觉风格全局一致，与三色体系无冲突。
