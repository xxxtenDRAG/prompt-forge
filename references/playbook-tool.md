# 工具 Playbook — 小工具与脚本速查基线

小工具/脚本/自动化类任务在通用七视角基础上叠加本基线。默认约束：即开即用、零配置、单次运行可完成目标。

---

## 输入输出定义

- 输入定死：格式（文件/文本/拖拽）、示例样例、大小上限、编码默认值。
- 输出定死：格式、命名规则、输出位置；错误时输出什么。
- 输入非法（空、超限、错格式）必须有明确报错信息，禁止静默失败。

## 交互与使用方式

- 优先级：命令行参数 > 简单界面 > 配置文件；默认参数开箱即用，零参数也能跑。
- 批量处理时显示进度；处理完成显示统计（成功/跳过/失败计数）。
- 危险操作（覆盖、删除、写入）默认关闭或需要显式确认开关。

## 健壮性

- 依赖最小化：能用标准库不用第三方；必须依赖时锁版本。
- 单个条目失败不中断整体批处理，结束时汇总失败清单。
- 幂等安全：重复运行不产生脏数据。

## 常见坑

- Windows 路径与中文文件名兼容（编码用 UTF-8，路径处理不用硬编码斜杠）。
- 大文件流式处理，不一次性读入内存。
- 异常退出时清理临时文件。

## 专属验收项（叠加进验收清单）

- [ ] 空输入、非法输入、边界输入三类用例实测通过，报错信息可读。
- [ ] 零参数默认运行成功完成核心功能。
- [ ] 输出结果抽样人工核对正确。
- [ ] 提供使用说明（一段话即可：装什么、跑什么、得到什么）。
