# 数据 Playbook — 数据分析速查基线

数据分析类任务在通用七视角基础上叠加本基线。默认约束：结论可复现、口径可追溯、图表能独立成话。

---

## 问题定义

- 把模糊问题翻译成可回答的分析问题："销售额怎么样" → "各区域月度销售额趋势与增长驱动"。
- 定成功标准：分析完成后能回答的 3 个具体问题，写进蓝图。
- 定决策用途：分析结果给谁、用于什么决策，决定深度与呈现形式。

## 数据与口径

- 数据来源定死：用户提供文件 / 公开数据 / 模拟数据（模拟数据必须显式标注）。
- 每个指标给出计算口径（公式、过滤条件、时间窗），全文唯一。
- 数据清洗规则显式列出（去重、缺失处理、异常值处理），并报告清洗损耗。

## 方法与验证

- 方法与问题匹配：趋势→时序，构成→占比，归因→分组对比，关系→相关性。
- 结论区分"数据事实"与"业务解读"，两者分开陈述。
- 主动找反例：给出至少 1 个"数据之外的另一种解释"并讨论。

## 呈现

- 图表服务于结论：先写结论再选图，一张图回答一个问题。
- 图表规范：标题即结论、轴标签带单位、关键点标注数字。
- 最终交付：摘要（3 条结论）→ 图表 → 方法与口径附录。

## 常见坑

- 辛普森悖论与相关性当因果。
- 小样本下给确定性结论。
- 图表美化过度牺牲可读性。

## 专属验收项（叠加进验收清单）

- [ ] 3 个目标问题全部有明确回答。
- [ ] 每个数字可追溯口径与来源。
- [ ] 模拟数据/假设有显式标注，与事实数据不混淆。
- [ ] 图表标题即结论，仅看图能懂。
- [ ] 结论包含限制条件与不确定性说明。
